# 📺 Projeto RMI - Controle Remoto em Java

Este projeto implementa uma aplicação **Cliente/Servidor usando Java RMI (Remote Method Invocation)**.  
A ideia é simular as funções básicas de um controle remoto de TV, permitindo que um **cliente** se conecte a um **servidor** e execute operações remotamente.

---

## 🚀 Funcionalidades
O controle remoto emula pelo menos 5 funções básicas de uma TV:

- **Ligar a TV**  
- **Desligar a TV**  
- **Aumentar o volume**  
- **Diminuir o volume**  
- **Mudar de canal**

Todas as funções são acessadas a partir do cliente, que envia comandos ao servidor.
